# 목적

> 셀 표기: `—` 는 빈 문자열, `␣` 는 공백 1칸이다(값 보존용). 표를 고친 뒤 `python3 tools/md_to_json.py build` 로 JSON 을 재생성한다 — 규약: `.claude/rules/data-md-first-rules.md`

n3sh(Karabiner)와 fSnippet(prj9)의 **역할 분담 경계** 문서다. 글자 하나 + (기호) 조합은 n3sh(Karabiner complex_modifications)가 처리하고, **두 글자 이상 축약부터는 fSnippet 담당**이다. 이 문서는 fSnippet 담당 영역(`_한글속기` 스니펫 세트)을 본 프로젝트 안에서 사람 정본으로 관리해 두 시스템을 연동(기능 설계 포함)하기 위해 존재한다.

# 동작

Keyword(로마자 키 시퀀스)를 그대로 타이핑한 뒤 **백틱(`)** 을 누르면 fSnippet 이 Snippet 텍스트로 치환한다.

* ex) `i` → `u` → 백틱 ⇒ `맞다.␣` — 390 배열에서 `i`=ㅁ, `u`=ㄷ 이므로 Label 은 `ㅁㄷ`
* Label 은 스니펫 파일명에 기록된 한글(390 자모) 표기 — 사람이 Keyword 를 암기하는 근거다

# 파일명 인코딩 (기준 폴더)

스니펫 1건 = 파일 1개, `{Keyword}==={Label}.txt` (파일 내용 = 확장 텍스트). 파일명에 쓰기 곤란한 특수문자는 토큰으로 인코딩돼 있다:

| 토큰            | 문자 |
| --------------- | ---- |
| `{apostrophe}`  | `'`  |
| `{comma}`       | `,`  |
| `{period}`      | `.`  |
| `{semicolon}`   | `;`  |
| `{slash}`       | `/`  |
| `{backslash}`   | `\`  |
| `{lbracket}`    | `[`  |
| `{underbar}`    | `_`  |

아래 표의 Keyword·Label 은 토큰을 **문자로 복원한 값**이다.

# 주의

* 이 항목들은 **Karabiner 설정에 존재하지 않는다**. 라이브 config 에서 찾아도 안 나오는 것이 정상이다(fSnippet 담당 영역).
* 폴더 부속 3종은 JSON 생성 대상에서 제외했다: `Icon`·`icon.png`(폴더 아이콘) · Keyword `___memo__`(운용 메모 스니펫 — 다행 텍스트라 md 셀 왕복 규약 밖. 원문은 기준 폴더에서 직접 확인).
* Keyword `h`(Label ㄴ) 는 스냅샷 시점에 **타건 실험 잔여물**(`짖`·`잖` 반복, Issue27 실험 글자)이 들어 있었다 — 실스니펫 값이 아니라 판단해 **빈값(`—`)으로 정본화**. 확정 값이 생기면 이 표를 고치고 build 할 것.
* Keyword `,` 는 기준 폴더 파일명에 `===Label` 부분이 없다 — Label 빈값으로 보존.
* 구 명칭 `alfred-snippets.md`/`alfred_snippets.json`(Numbers "Alfred Snippet로" 표 12건)은 본 문서로 대체됐다(Issue31) — Alfred → fSnippet 이관 후 실데이터 기준.
