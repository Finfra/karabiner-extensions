> 📝 **매뉴얼 계열 초안** — [training.md](training.md)(매뉴얼 초안)와 짝인 **한 장 요약**. 단계별로 익히는 것은 매뉴얼이 맡고, 여기서는 결과만 훑는다.

[6단계 학습 드릴](training.md)과 짝인 **한 장 요약**이다. 익히는 순서·드릴은 그쪽이, 단계 배정 근거는 [rules_step.md](../../layout/n390/rules_step.md) 가 맡는다. 여기는 **무엇을 누르면 무엇이 나오는지만** 담는다.

# 읽는 법

* `글자 키키` — 두 키를 **동시에** 누른다. 두 키끼리는 순서가 없다
* `␣` = 스페이스바 · `⏎` = 엔터 · `~ㅂ` = 종성(초성과 다른 자리)
* **모디파이어는 전치** — `⌘kj` 는 ⌘ 를 **누른 채** k+j. 적힌 순서가 곧 누르는 순서다([training.md](training.md) 와 같은 표기 — [rules_step.md](../../layout/n390/rules_step.md) 는 후치를 쓰니 혼용하지 말 것)
    - ⚠️ **모디파이어가 먼저다.** 자모를 친 **뒤에** ⌥·⇧·⌘ 를 누르면 발동하지 않는다 — 키가 눌리는 순간의 상태로 판정되므로 그때는 이미 늦다
* **조사·어미는 뒤 공백까지 함께** 나온다. 그래서 아래 글자 뒤에 스페이스바를 또 누르지 않는다

## 모디파이어 메타 규칙 (2·3단계)

같은 트리거에서 문장부호가 갈린다 — **이 한 줄이 3단계 107행을 30개로 줄인다.**

| 무수식     | ⇧          | ⇧+⌘        | ⌘                | ⌥                       |
| :--------- | :--------- | :--------- | :--------------- | :---------------------- |
| `.` + 공백 | `?` + 공백 | `!` + 공백 | 부호 없이 공백만 | 부호·공백**둘 다 없음** |

아래 목록은 **무수식 형태만** 적는다. 트리거가 갈리는 것(면·데·던·께·까)만 수식키를 **앞에** 적었다.

# 자판 지도

초성 키 배치:

```
                ㅋ(0)
  ㄹ(y)  ㄷ(u)  ㅁ(i)  ㅊ(o)  ㅍ(p)
  ㄴ(h)  ㅇ(j)  ㄱ(k)  ㅈ(l)  ㅂ(;)  ㅌ(')
  ㅅ(n)  ㅎ(m)
```

# 예비 — 동시타 확인

```
.  cv     .  .,
```

# 1단계 — 쌍자음·복모음

```
ㄲ kj    ㄸ ui    ㅃ ;p    ㅆ nj    ㅉ lk
ㅑ fd    ㅠ er    ㅖ rt    ㅒ rf
```

# 2단계 — 조사·짧은 기능어

```
조사
        이 dc    히 de    가 fe    은 jl    는 hl    을 jh    를 yu
        로 yi    도 uo    고 km    과 k.    와 j.    에 j␣    게 k␣
        인 jy    의 8␣
기능어
        만 i␣    면 ⇧i␣    더 u␣    데 ⇧u␣    던 ⌥u␣
        한 m␣    할 m,    수 n␣    서 n'
부정
        안 23    않 13
```

# 3단계 — 종결어미

```
평서    다 u;      해 m;    야 d.    아 f.    어 j⏎    지 o;    죠 l'
        요 j'      오 j;    소 n;    네 h;    군 k'    돼 ul    리 y8
의문    까 ⌘kj   가 k;    나 hu    냐 hi    니 ho    래 y;
청유    자 l;      줘 l,    봐 ;'    마 i;    라 y7
명사형  함 ml      음 jm    임 ju    기 kp
높임    께 ⌘k␣
```

⚠️ `kj` 무수식은 1단계 ㄲ, `k␣` 무수식은 2단계 게다 — **같은 키를 수식키로 가른다.** 그래서 ⌘ 를 늦게 누르면 까 대신 ㄲ 이, 께 대신 게 가 나간다.

# 4단계 — 자모(종성·이중모음)

```
종성    ~ㄷ aw   ~ㅌ wq   ~ㅊ zs   ~ㅍ q2   ~ㄲ 1w   ~ㄶ sa   ~ㅄ xz
이중모음 ㅘ f␣    ㅙ r␣    ㅚ v␣    ㅝ t␣    ㅞ c␣    ㅟ d␣    ㅢ g␣
```

* 종성은 손가락 인접성과 무관하다 — 니모닉 없이 외운다
* 이중모음은 **모음 키 + 스페이스바**. 2단계 에(`j␣`)·게(`k␣`)·의(`8␣`)와 같은 손놀림이다

# 5단계 — 1·2·3받침

초성 키에 `1`·`2`·`3` 을 붙인다(ex: `k` 자리 → 갖 `k1` · 겠 `k2` · 갑 `k3`). 아래 세 지도는 **자판 배치 그대로**라, 위 자판 지도에서 초성 키를 찾으면 같은 자리다.

`c1+1` 열 (`~ㅈ`·`~ㅎ` 계열):

```
              ·
  렇    딪    맞    찾    ·
  낮    잊    갖    짖    빚    ·
  싫    ·
```

`c1+2` 열 (`~ㅆ` 과거 활용형):

```
              켰
  랬    됐    몄    쳤    폈
  냈    왔    겠    졌    봤    탔
  셨    했
```

`c1+3` 열 (`~ㅂ`):

```
              큽
  롭    됩    맙    춥    팝
  납    입    갑    집    뵙    탑
  습    합
```

* 열 규칙: `+1` = `~ㅈ`·`~ㅎ` 계열 · `+2` = 과거 활용형(`~ㅆ`) · `+3` = `~ㅂ` 계열
* `·` 는 **미할당 자리**다 — ㅋ(`0`)·ㅍ(`p`)·ㅌ(`'`)·ㅎ(`m`)에는 `+1` 이 없다

# 6단계 — 낱글자

묶을 규칙이 없다. 개별 암기 구간이다.

```
ㅇ초성
        았 j[    없 j,    었 jo    였 jp    원 j]
        월 j\    읽 j-    잃 j0    있 ji
복잡글자
        괜 kh    것 ko    끊 k,    넣 hm    년 hp    넷 h[
        님 hy    놓 hn    능 h.    뭘 i9    많 io    좋 li
        잖 lo    줄 l␣    적 l.    활 m.    찮 op    된 u8
        될 u[    들 up    떻 uk    윈 9s
체언·부사
        등 u0    후 mn    즉, lp   행, m'
```

* ㅇ초성 9종은 전부 `j` 로 시작한다 — 시작 지점이 고정이라 뒤만 외우면 된다
* `즉`·`행` 은 **쉼표가 붙어 나온다**(`즉,␣`). ⌘ 를 **누른 채** 치면 쉼표 없이 `즉␣`·`행␣`
