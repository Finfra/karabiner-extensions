> 📝 **매뉴얼 계열 초안** — [training.md](training.md)(매뉴얼 초안)와 짝인 **한 장 요약**. 단계별로 익히는 것은 매뉴얼이 맡고, 여기서는 자판 배치를 한눈에 훑는다.

# 자판 지도

초성 키 배치(참조):

```
                ㅋ(0)
  ㄹ(y)  ㄷ(u)  ㅁ(i)  ㅊ(o)  ㅍ(p)
  ㄴ(h)  ㅇ(j)  ㄱ(k)  ㅈ(l)  ㅂ(;)  ㅌ(')
  ㅅ(n)  ㅎ(m)
```

키별 덩어리(`+1`·`+2`·`+3` 세 글자를 붙여 읽는다 — 낭송 드릴은 [training.md](training.md) "덩어리 낭송"):

```
                    ᄏ켰큽
  렇랬롭  딪됐됩  맞몄맙  찾쳤춥  ᄑ폈팝
  낮냈납  잊왔입  갖겠갑  짖졌집  빚봤뵙  ᄐ탔탑
  싫셨습  ᄒ했합
```

`ᄏ`·`ᄑ`·`ᄐ`·`ᄒ` 는 `+1` 미할당이라 초성만 나가는 자리다(아래 열별 지도에서는 `·`).

`c1+1` 열 (`~ㅈ`·`~ㅎ` 계열):

```
              ·
  렇    딪    맞    찾    ·
  낮    잊    갖    짖    빚    ·
  싫    ·
```

`c1+2` 열 (`~ㅆ` 과거 활용형):

```
              켰
  랬    됐    몄    쳤    폈
  냈    왔    겠    졌    봤    탔
  셨    했
```

`c1+3` 열 (`~ㅂ`):

```
              큽
  롭    됩    맙    춥    팝
  납    입    갑    집    뵙    탑
  습    합
```
