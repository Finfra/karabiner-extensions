# 표기법

공통 표기(동시타 · 타건 구분 `·` · fSnippet 백틱 `` ` `` · 스페이스바 `␣`)는 [notation.md](../notation.md) 가 SSOT 다. 본 문서 고유 사항만 적는다.

* **모디파이어는 전치** — `{cmd}o;`. [rules_step.md](../../layout/n390/rules_step.md)는 후치(`o;`+⌘)를 쓰니 **혼용하지 말 것** (대응표: [notation.md](../notation.md) "모디파이어")
    - ⚠️ **적힌 순서가 곧 누르는 순서다.** 모디파이어를 **먼저 눌러 두고** 자모를 친다 — 자모를 친 뒤에 ⌥·⇧·⌘ 를 누르면 발동하지 않고 무수식 행이 나가거나 아무것도 안 나간다. 특히 `{cmd}kj`(까)를 늦게 누르면 ㄲ 이, `{cmd}k␣`(께)는 게 가 나간다
* **키 순서는 `c1`·`c2` 순으로 적는다** — 동시타라 실제로는 순서가 없지만, 표기는 [rules.md](../../layout/n390/rules.md) 컬럼 순서를 따른다(구 판의 `;o` 는 뒤집힌 표기였다). **모디파이어는 이 "순서 없음"에서 제외**다 — 자모 둘보다 앞서 있어야 한다
* **⟨ ⟩ 는 평타** — 규칙이 없어 자모를 그대로 치는 음절이다. ex) ⟨괜⟩ 이 아니라 `kh` 처럼 트리거가 생긴 글자는 ⟨ ⟩ 를 벗긴다
* **출력의 `␣`** 는 자동으로 붙는 공백이다. 손으로 스페이스바를 누르는 것이 아니다
* **시퀀스의 단독 `␣`** 는 반대로 **손으로 누르는 스페이스바**다. `k␣` 처럼 트리거 안에 붙은 `␣` 는 그 트리거의 둘째 키다 — 자리가 다르니 헷갈리지 말 것
* **드릴 표의 `id` 는 [rules.md](../../layout/n390/rules.md) 의 행 번호다.** 그 순서 자체가 **손의 흐름**이라 임의로 재정렬하지 않고 그대로 따른다 — 표를 외우는 순서가 곧 id 순서다

## 꼬리 규칙 (전 단계 공통 — 먼저 익힐 것)

행마다 외우는 것이 아니라 **메타 규칙 하나**다. 상세·근거: [rules_notes.md](rules_notes.md) 규칙1~3.

| 수식키 | 결과                                  | 예 (`y;` = 래)          |
| :----- | :------------------------------------ | :---------------------- |
| 무수식 | `기호` 컬럼대로 — 어미는 대개 `.`     | `y;` → 래.␣             |
| `⇧`    | `?`                                   | `{shift}y;` → 래?␣      |
| `⇧⌘`   | `!`                                   | `{shift}{cmd}y;` → 래!␣ |
| `⌘`    | **행마다 다름** — 대개 기호만 억제    | `{cmd}y;` → 래␣         |
| `⌥`    | **꼬리 없음** — 공백도 기호도 안 붙음 | `{opt}y;` → 래          |

⚠️ 최종식은 `⇧`·`⇧⌘` 가 반대다. 390 은 위 표가 맞다.

⚠️ **다섯 변형이 다 있는 트리거는 오히려 소수다.** 없는 조합을 치면 그냥 원래 키가 나간다 — 각 단계 표의 `—` 는 "그 조합은 등록돼 있지 않다"는 뜻이다.

# 진행 규약

* **아래 단계까지 배운 것만 쓴다** — 각 단계의 연습 문장은 그 단계 이하의 트리거 + 평타 ⟨ ⟩ 로만 짰다. 앞서 배운 것이 뒤에서 계속 재등장한다
* 단계당 **드릴 표 3회전 → 문장 표 3회전**. 오타가 난 트리거는 그 단계 드릴 표로 돌아간다
* 1~3단계는 규칙 재사용성이 높아 빠르게 지나가고, 4단계부터는 반복 주기를 늘린다([rules_step.md](../../layout/n390/rules_step.md) "진행 순서 요약")

# 예비 단계 — 동시타 확인

세벌식 지식이 아니라 **장비가 동시타를 받는지** 보는 워밍업이다. 둘 다 출력이 마침표 자체다.

| id      | 트리거 | 출력 | 비고          |
| :------ | :----- | :--- | :------------ |

두 개 다 마침표가 나오면 통과. 안 나오면 훈련이 아니라 장비·설정 문제다.

# 4단계 — 자모(종성·이중모음)

여기서 **모디파이어 재사용 규칙이 처음 끊긴다.** 출력이 자모 하나뿐이라 단순해 보이지만 니모닉이 없어 순수 반복 암기 구간이다. 앞 7종(종성)과 뒤 7종(이중모음)은 입력 메커니즘이 서로 다르니 나눠 익힌다.

## 종성 자모 — 홑받침 5 → 겹받침 2

| id      | 트리거  | 출력   | 조합 예 (평타 음절 + 종성 동시타)         |
| :------ | :--- | :--- | :---------------------------- |
| `4-001` | `aw` | `~ㄷ` | ⟨고⟩·`aw` → 곧                  |
| `4-002` | `wq` | `~ㅌ` | ⟨바⟩·`wq` → 밭                  |
| `4-003` | `zs` | `~ㅊ` | ⟨나⟩·`zs` → 낯                  |
| `4-004` | `q2` | `~ㅍ` | ⟨아⟩·`q2` → 앞                  |
| `4-005` | `1w` | `~ㄲ` | ⟨바⟩·`1w` → 밖                  |
| `4-006` | `sa` | `~ㄶ` | ⟨아⟩·`sa` → 않 (2단계 `13` 의 정공법) |

* **전부 종성이다** — 그래서 `~` 를 붙여 적는다([notation.md](../notation.md) "자모")
* `1w`(종성 ㄲ)와 1단계 `kj`(초성 ㄲ)를 헷갈리지 말 것. **밖** 은 이 종성으로 친다 — 별도 트리거가 없다
* 앞 5개가 홑받침, 뒤 2개(`sa`·`xz`)가 겹받침이다

## 이중모음 자모 — ㅗ계 3 → ㅜ계 3 → ㅢ

"두 키 동시타"가 아니라 **모음 키 + 스페이스바** 라는 별도 메커니즘이다.

| :------ | :--- | :- | :---- |
| `4-008` | `f␣` | ㅘ  | 과·완·활 |
| `4-009` | `r␣` | ㅙ  | 왜·괜   |
| `4-010` | `v␣` | ㅚ  | 외·되   |
| `4-011` | `t␣` | ㅝ  | 워·원   |
| `4-012` | `c␣` | ㅞ  | 웨·궤   |
| `4-013` | `d␣` | ㅟ  | 위·귀   |
| `4-014` | `g␣` | ㅢ  | 의·희   |

* 첫 모음이 같은 것끼리 묶여 있다 — ㅗ계(ㅘ·ㅙ·ㅚ) → ㅜ계(ㅝ·ㅞ·ㅟ) → ㅢ. 종성 절과 달리 이만큼은 규칙이 있다
* 2단계의 `j␣`(에)·`k␣`(게)·`8␣`(의)도 스페이스바 조합이었다 — **같은 손놀림, 다른 산출물**

# 5단계 — 1·2·3받침

두 번째 키가 `1`·`2`·`3` 중 하나로 고정된 **열(column) 규칙**이 있어, 개별암기처럼 보여도 표로 외워진다. 초성 키 배치는 [training_cheatsheet.md](training_cheatsheet.md) "자판 지도" 참조.

## 드릴 — 초성 한 줄씩 (손의 흐름 순)

열을 세로로 훑는 것이 아니라 **한 초성을 잡고 `1`·`2`·`3` 을 차례로 누르는** 것이 손의 흐름이다. 아래 표는 그 흐름대로 배열했다 — [rules.md](../../layout/n390/rules.md) 의 id 는 초성 **가나다 순**(`k`→`h`→`u`→`y`→…)이라 표 순서와 다르다.

| id                | 초성   | `+1` (`~ㅈ`·`~ㅎ`) | `+2` (과거형) | `+3` (`~ㅂ`) |
| :---------------- | :----- | :----------------- | :------------ | :----------- |
| `5-001`~`5-003`   | ㄱ `k` | 갖                 | 겠            | 갑           |
| `5-004`~`5-006`   | ㄴ `h` | 낮                 | 냈            | 납           |
| `5-007`~`5-009`   | ㄷ `u` | 딪                 | 됐            | 됩           |
| `5-010`~`5-012`   | ㄹ `y` | 렇                 | 랬            | 롭           |
| `5-013`~`5-015`   | ㅁ `i` | 맞                 | 몄            | 맙           |
| `5-016`~`5-018`   | ㅂ `;` | 빚                 | 봤            | 뵙           |
| `5-019`~`5-021`   | ㅅ `n` | 싫                 | 셨            | 습           |
| `5-022`~`5-024`   | ㅇ `j` | 잊                 | 왔            | 입           |
| `5-025`~`5-027`   | ㅈ `l` | 짖                 | 졌            | 집           |
| `5-028`~`5-030`   | ㅊ `o` | 찾                 | 쳤            | 춥           |
| `5-031`~`5-032`   | ㅋ `0` | —                  | 켰            | 큽           |
| `5-033`~`5-034`   | ㅌ `'` | —                  | 탔            | 탑           |
| `5-035`~`5-036`   | ㅍ `p` | —                  | 폈            | 팝           |
| `5-037`~`5-038`   | ㅎ `m` | —                  | 했            | 합           |

* **딪·맞·탔은 나중 편입분**이지만 2026-08-05 단계 재편 때 id 가 초성 가나다 순으로 다시 매겨져 지금은 제자리 번호다(`5-007`·`5-013`·`5-033`) — 더 이상 끝번이 아니다
* 2열은 "자음 + `2` = 그 자음의 과거형" 공식 하나로 통일된다. 세로로 훑고 싶을 때는 [training_cheatsheet.md](training_cheatsheet.md) 의 열별 자판 지도를 본다

## 덩어리 낭송 — 자리 순서로 세 글자씩

위 표는 **가나다 순**이라 눈으로 대조하기 좋지만, 손은 가나다 순으로 놓여 있지 않다. 외울 때는 **자판에 놓인 자리 순서**로 훑고, 한 초성의 `1`·`2`·`3` 을 **세 글자 한 덩어리로 붙여 소리내어** 읽는다.

이 형태가 이 단계의 핵심이다 — 초성 키 하나를 짚으면 세 글자가 통째로 딸려 나오므로, **낱건 38개가 아니라 덩어리 14개**를 외우는 일이 된다.

```
                    ᄏ켰큽 (0)
  렇랬롭 (y)  딪됐됩 (u)  맞몄맙 (i)  찾쳤춥 (o)  ᄑ폈팝 (p)
  낮냈납 (h)  잊왔입 (j)  갖겠갑 (k)  짖졌집 (l)  빚봤뵙 (;)  ᄐ탔탑 (')
  싫셨습 (n)  ᄒ했합 (m)
```

* **`ᄏ`·`ᄑ`·`ᄐ`·`ᄒ` 는 글자가 아니라 빈칸이다.** `0`·`p`·`'`·`m` 의 `+1` 에는 규칙이 없어, 쳐 보면 초성 자모만 그대로 나간다. 덩어리의 **모양 자체가 그 구멍을 기억시키므로** `·` 로 지우지 않고 나온 대로 적었다([training_cheatsheet.md](training_cheatsheet.md) 의 열별 지도는 `·` 를 쓴다 — 거기서는 열이 주인공이라 자리만 비우면 된다)
* 14덩어리 × 3 = 42칸 중 빈칸 4개를 빼면 **38행**으로, 위 드릴 표와 수가 맞는다
* 덩어리는 뜻이 없는 소리다 — "렇랬롭", "딪됐됩" 을 단어로 이해하려 하지 말고 **음절 리듬**으로 굳힌다. 뜻은 뒤의 문장 드릴에서 붙는다
* 자리 순서라 **같은 줄에 손가락이 이어져 있다** — 윗줄 5덩어리, 가운뎃줄 6덩어리, 아랫줄 2덩어리, 숫자열 1덩어리로 끊어 회전한다

## 종합 예문 — 한 줄에 여러 글자

앞 표가 글자를 하나씩 짚는 것이라면, 여기는 **실제로 쓰는 문장 안에서 여러 개가 연달아 나오는** 연습이다. 5단계 38글자가 아래 18문장에 **빠짐없이 한 번 이상** 들어간다.

* **한 줄씩 외운다.** 전부 일상에서 실제로 쓰는 말이라, 문장째 손에 붙으면 그 안의 글자는 따로 떠올리지 않아도 나온다
* **예문 열은 읽기 위해 그대로 뒀다** — 평타 ⟨ ⟩ 표시는 시퀀스 열에만 있다
* **문장 안의 공백은 대부분 자동이다.** 조사·어미가 알아서 붙이므로, **시퀀스에 `␣` 가 보이는 자리에서만** 스페이스바를 누른다
* `{opt}` 가 붙은 자리(`{opt}hl` = 는)는 **꼬리를 없애는 것**이다 — "찾았는데" 처럼 조사가 단어 중간에 올 때 자동 공백이 끼는 것을 막는다. 꼬리 규칙 표의 ⌥ 행이 여기서 처음 실전으로 쓰인다

# 종합 문장

전 단계를 섞는다. `` ` `` 로 시작하는 것은 fSnippet 축약이라 Karabiner 규칙이 아니다([fsnippet-한글속기.md](fsnippet-한글속기.md)).

| 문장                            | 시퀀스                                      |
| :------------------------------ | :------------------------------------------ |
| 맞습니다.␣                      | `` i1·n` ``                                 |
| 찾겠습니다.␣                    | `` o1·,` `` (fSnippet `,`=겠습니다)         |
| 많이␣갖고␣있습니다.␣            | `` io·dc·k1·km·ji·n` ``                     |
| 잊지␣않겠습니다.␣               | `` j1·{cmd}o;·13·k2·n` ``                   |
| 빚을␣⟨갚⟩지␣않겠습니다.␣        | `` ;1·jh·⟨갚⟩·{cmd}o;·13·k2·n` ``           |
| 쉽지␣않습니다.␣                 | `` ⟨쉽⟩·{cmd}o;·13·n` ``                    |
| 안␣쉽다.␣ 즉,␣⟨하⟩기␣⟨어⟩렵다.␣ | `` 23·⟨쉽⟩·u;·lp·⟨하⟩·kp·⟨어⟩·y1·u; ``      |
| 안␣쉽습니다.␣                   | `` 23·⟨쉽⟩·n` ``                            |

# 규칙에서 빠진 글자 — 평타로 친다

트리거가 없는 것은 없다고 알고 있어야 손이 헤매지 않는다.
