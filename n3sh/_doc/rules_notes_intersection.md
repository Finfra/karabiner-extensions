* **수정 가능** — 양 배열에 **공통인 규칙**을 여기 모은다. 배열별로 갈리는 것은 각 판 문서로
* **배열별 적용본**: [n390/rules_notes.md](n390/rules_notes.md) (390) · [final/rules_notes.md](final/rules_notes.md) (최종식)
* 전체 Rule: 배열별 [n390/rules.md](../layout/n390/rules.md)·[final/rules.md](../layout/final/rules.md) · 교집합 [rules_Intersection.md](../layout/rules_Intersection.md)

> ⚠️ **SSOT 예외 문서다.** 아래 공통 규칙은 배열별 문서에도 같은 내용이 있다 — "둘이 같다"는 사실 자체를 한자리에서 보이려고 **일부러 중복 보유**한다(사용자 판정 2026-08-04).
>
> **갈라지면 배열별 문서가 이긴다.** 여기는 모아 보는 곳이지 판정하는 곳이 아니다. 한쪽 배열에서만 규칙이 바뀌면 그 순간 공통이 아니므로, 여기서 빼고 "배열별로 갈리는 것" 절로 옮긴다.
>
> 이름이 [rules_Intersection.md](../layout/rules_Intersection.md)(규칙 **데이터** 교집합)와 짝을 이룬다 — 그쪽은 **도구가 계산**한 파생 뷰라 직접 편집 금지지만, 여기는 **사람이 손으로** 모으는 규칙 **서술** 교집합이다.

# 공통 규칙 — 양 배열 동일

전건 실측 확인분이다(2026-08-04). 배열별 수치 차이는 행 수 차이일 뿐 규칙 자체는 같다.

| # | 규칙 | 390 | 최종식 |
| :- | :--- | :--- | :--- |
| 1 | **조사·명사형 뒤에 공백이 자동으로 붙는다** (`sp=✔` → 끝에 `spacebar`) | 조사 26/31 · 명사형 11/11 | 조사 24/29 · 명사형 11/11 |
| 2 | **`⌥` 변형은 꼬리가 없다** — `기호`·`sp` 컬럼과 무관하게 자모만. **컬럼보다 이 규칙이 우선** | 16행 전량, 예외 0 | 16행 전량, 예외 0 |
| 4 | **같은 트리거를 두 행이 쓸 수 없다** — `(c1,c2,⌥,⇧,⌘)` 유일. 뒤엣것은 죽은 규칙 | 🚧 `함` 1건 미해소 | 🚧 `함` 1건 미해소 |
| 3 | **기호 대응 `⇧`=`?` · `⇧⌘`=`!`** (무수식 `.`) — 2026-08-06 양 배열 실기 확인 | `⇧+h+i`→`냐?` | `⇧`+`/`→`?` · `⇧`+`b`→`!` |
| 5 | **실제로 쓰는 기호 키는 10종** — `' , - . ; [ \ ] ␣ ⏎` | 동일 | 동일 |
| 6 | **조사는 패턴 규칙이라 `억지` 가 아니다** — `억지=✔` 는 자모 조립이 불가능한 행에만. 그 literal 은 오라클 `manual_overrides` 로 | — | — |

* 번호는 배열별 문서의 규칙 번호와 맞춘다. 3번은 2026-08-06 까지 "배열별로 갈리는 것" 에 있었으나 **실기 확인으로 공통임이 밝혀져 이 표로 올라왔다**
* 집행 코드: 규칙4 → `tools/validate_schema.py` `check_trigger_unique` · 규칙2 → `tools/n3sh/keymap_derive.py` `rec_symbols`

# 배열별로 갈리는 것

| # | 항목 | 390 | 최종식 |
| :- | :--- | :--- | :--- |
| — | `ㅒ` 트리거 | `r+f` | `g+f` |
| — | `해`(`m+;`+⌘) | staging `지정안할` 이관 | 정본에 `x=✔`(구 `비활성`) 으로 잔존 |

* ⚠️ 한때 기호 대응이 여기 있었다 — "키코드는 같으니 차이가 난다면 OS 배열이 다른 문자를 내기 때문" 이라는 가설이었다. **실측으로 기각**됐다: 두 배열의 기호 대응은 같고, 원문(Numbers)이 틀렸다
* 최종식은 라이브 미배포라 계산값이다. 실기 확인된 390 과 **확실성 등급이 다르다**
* 트리거 차이 전체 목록: [keymap_final_to_390.json](../core/keymap_final_to_390.json)
