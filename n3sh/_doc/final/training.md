# 개요

> 셀 표기: `—` 는 빈 문자열, `␣` 는 공백 1칸이다(값 보존용). 표를 고친 뒤 `python3 tools/md_to_json.py build` 로 JSON 을 재생성한다 — 규약: `.claude/rules/data-md-first-rules.md`

규칙 자체가 아니라 **손에 익히기 위한 자료** 중 **배열 중립(공통)** 만 이 파일에 둔다. 고쳐도 Karabiner 동작은 바뀌지 않는다. **배열 전용 훈련은 각 배열 폴더로 분리** (2026-08-02):

| 최종식   | [final/training.md](training.md) — (자리 — 전용 자료 없음) |

# 1·2열 연습

1열·2열 자리의 받침 조합을 반복 타건하기 위한 문장 세트다. 원본 셀의 앞뒤 공백은 추출 원문 그대로 보존돼 있다.

<!-- data: practice.json -->
| id  | 1열       | 2열    |
| --- | --------- | ------ |
| 1오 | 엮다.␣    | 읽다.␣ |
| 2오 | 깊다.␣␣␣␣ | 잍다.␣ |
| 3오 | 읻다.␣    | 않다.␣ |
| 4오 | 꽃다.␣    | 없다.␣ |

| 컬럼  | 의미                                       |
| :---- | :----------------------------------------- |
| `id`  | 행 식별자(`1오`~`4오`) — 원본 표의 행 머리 |
| `1열` | 1열 받침 연습 단어                         |
| `2열` | 2열 받침 연습 단어                         |

# 암기용

# 주의

* `c2` 의 `1.0` 표기는 도구가 `normalize_key` 로 흡수하지만, 사람이 읽을 때 헷갈리지 말 것.
* 동작을 바꾸려면 정본([rules.md](../../layout/final/rules.md) / `final/rules.json`)을 고쳐야 한다.
