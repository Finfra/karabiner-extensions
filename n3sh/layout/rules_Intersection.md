Issue6에서 `tools/numbers_extract.applescript` + `numbers_to_json.py`로 자동 생성(구 `highlight` 열 — 원본 셀 배경색/글자색이 컬럼 최빈값과 다름을 표시하던 메타데이터, 빌드 미사용 확인 후 Issue44로 제거). 규칙 자체의 자연어 서술은 [rules_notes_intersection.md](../_doc/rules_notes_intersection.md) 참조.

Numbers 원본 경로·시트 구획 → 산출 파일 매핑은 `_doc_arch/numbers-extraction-map.md` 로 분리(2026-08-02).
