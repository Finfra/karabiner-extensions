**세벌식 최종식 판의 완전한 규칙표 정본**이다 (총 229행 — 오라클 정합 역사 기준 판). ⚠️ **불변식**: 본 판은 keymap 역추론의 학습 소스다 — 오라클과 어긋나게 바꾸면 양 배열 키맵 학습이 영향받는다(`gen_rules` 대조가 fail-loud). 390 판은 [n390/rules.md](../n390/rules.md), 교집합 뷰는 [rules_Intersection.md](../rules_Intersection.md).

> 셀 표기: `—` 는 빈 문자열, `␣` 는 공백 1칸이다(값 보존용). `c1`·`c2`(누르는 키) 컬럼의 `␣` 는 **스페이스바 키**를 뜻하며 JSON 에는 `_` 로 저장된다 — 같은 행 `txt` 의 `␣` 는 출력 공백이다. 뜻을 가르는 것은 컬럼이다. 표를 고친 뒤 `python3 tools/md_to_json.py build` 로 JSON 을 재생성한다 — 규약: `.claude/rules/data-md-first-rules.md`
>
> ✅ **`억지` 컬럼은 폐지됐다**(2026-08-06) — 전 229행이 자모 조립으로 산출되며 오라클은 **대조 기준으로만** 남는다. 미학습 심볼은 [keymap.md](../keymap.md) 에 **선언**한다
> 종성 낱자는 `txt` 에 **`~` 접두**로 적는다(`~ㄲ` = 종성, 접두 없는 `ㄲ` = 초성 `k k`) — 표기 SSOT: [notation.md](../../_doc/notation.md)
> 품사 등 컬럼 해설: [rules_Intersection.md](../rules_Intersection.md)

> 컬럼 변경: `c1n`·`c2n` 제거 — `c1`/`c2` 에서 파생한다(`keymap_derive.key_code`). `중요도` 는 값을 비웠다.
>
